# Privacy policy

Agent Plugins Author does not collect telemetry, send user content to a
service, or include an MCP server. The bundled skill operates on files supplied
by the user and on local validation results.

When the user explicitly requests an online upstream refresh, the refresh
helper reads public specification metadata from its documented allowlist. It
does not store credentials or transmit plugin contents to those sources. Local
reports and accepted snapshots remain in the user's workspace.

If a future release adds a networked service or data collection, this policy
will be updated before that capability is distributed.
